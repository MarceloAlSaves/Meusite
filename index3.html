1- Imagem de fundo

Para colocar uma imagem de fundo, utilize a propriedade background-image no CSS. Você pode especificar a URL da imagem que deseja usar como plano de fundo. Por exemplo:

        body {
            background-image: url("caminho/para/sua/imagem.jpg");
        }

Certifique-se de substituir "caminho/para/sua/imagem.jpg" pelo caminho real da imagem que você deseja usar. Você também pode ajustar outras propriedades de background, como background-size, background-repeat e background-position para controlar como a imagem é exibida no plano.

Com a prioridade de repeat, você pode controlar se a imagem será repetida horizontalmente, verticalmente ou não será repetida.

Exemplo:

        body {
            background-image: url("caminho/para/sua/imagem.jpg");
            background-repeat: no-repeat;
            background-size: cover;
        }

Isso fará com que a imagem de fundo seja exibida apenas uma vez e ocupe toda a área do plano de fundo, ajustando-se ao tamanho da tela.

Posição das imagens

Para controlar a posição das imagens em uma página web, você pode usar a propriedade CSS background-position. Essa propriedade permite especificar a posição da imagem de fundo em relação ao elemento em que ela está aplicada.

Exemplo:

        body {
            background-image: url("caminho/para/sua/imagem.jpg");
            background-position: center;
        }

Isso fará com que a imagem de fundo seja centralizada no elemento. Você também pode usar outras palavras-chave como top, bottom, left, right ou valores específicos em pixels ou porcentagem para posicionar a imagem de acordo com suas necessidades.

Outra coisa interessante é que voce pode deixar a imagem fixa no lugar, mesmo quando o usuário rola a página.

        body {
            background-image: url("caminho/para/sua/imagem.jpg");
            background-attachment: fixed;
        }

2- ShortHand

O shorthand em CSS permite que você defina múltiplas propriedades de uma vez, tornando o código mais conciso e legível. Por exemplo, em vez de escrever:

        body {
            background-image: url("caminho/para/sua/imagem.jpg");
            background-repeat: no-repeat;
            background-position: center;
        }

Você pode usar o shorthand:

        body {
            background: url("caminho/para/sua/imagem.jpg") no-repeat center;
        }

3- Tabelas

As tabelas em HTML são usadas para organizar e apresentar dados de forma tabular. Elas são criadas usando a tag table e podem conter linhas tr, células de dados td e células de cabeçalho th. As tabelas podem ser estilizadas usando CSS para melhorar sua aparência e legibilidade. Por exemplo, você pode adicionar bordas, alterar a cor de fundo, ajustar o espaçamento entre as células e muito mais. As tabelas são úteis para exibir informações estruturadas, como horários, preços, estatísticas e outros tipos de dados que se beneficiam de uma apresentação organizada, tambem existe a legenda da tabela como uma fonte de informação adicional. usando captionExemplo:

3.1- Css de tabelas

Para fazer um efeito zebra nas tabelas, você pode usar a propriedade CSS vertical-align. junto com o tag nth-child

        .tabela tr:nth-child(de quanto em quanto voce quer pular) {
            background-color: #f2f2f2;
        }

Isso fará com que as linhas pares da tabela tenham um fundo cinza claro, criando um efeito de zebra que melhora a legibilidade dos dados. Você pode ajustar a cor de fundo e a frequência do efeito de acordo com suas preferências.

3.2 - Tabela fixa

Para criar uma tabela fixa, onde o cabeçalho permanece visível enquanto o usuário rola o conteúdo, você pode usar a propriedade CSS position: sticky. Aqui está um exemplo de como fazer isso:

        .tabela thead {
            position: sticky;
            top: 0;
            background-color: #fff; /* Cor de fundo para o cabeçalho */
            z-index: 1; /* Garante que o cabeçalho fique acima do conteúdo */
        }

Isso fará com que o cabeçalho da tabela fique fixo no topo da página enquanto o usuário rola o conteúdo da tabela.

3.3- Mesclagem de células

Para mesclar células em uma tabela, você pode usar as propriedades CSS colspan e rowspan. A propriedade colspan especifica quantas colunas uma célula deve abranger, enquanto a propriedade rowspan especifica quantas linhas uma célula deve abranger.

Tabela reponsiva

Para tornar uma tabela responsiva, você pode usar a propriedade CSS overflow-x: auto em um contêiner que envolve a tabela. Isso permitirá que a tabela seja rolada horizontalmente em dispositivos com telas menores, garantindo que todo o conteúdo da tabela seja acessível sem quebrar o layout da página.

        .tabela-container {
            overflow-x: auto;
        }

Em seguida, você pode envolver sua tabela em um elemento com a classe "tabela-container" para aplicar essa funcionalidade.
