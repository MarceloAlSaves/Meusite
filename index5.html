1- Flexbox

O Flexbox é um modelo de layout em CSS que facilita a criação de layouts flexíveis e responsivos. Ele permite que os elementos dentro de um contêiner sejam organizados de forma eficiente, mesmo quando o tamanho dos elementos é desconhecido ou dinâmico. O Flexbox é especialmente útil para criar layouts de uma dimensão, como linhas ou colunas, e é amplamente utilizado para criar interfaces de usuário modernas e responsivas.

1.1- Propriedades do Flexbox

O Flexbox possui várias propriedades que controlam o comportamento dos elementos dentro do contêiner flexível. Algumas das principais propriedades incluem:

  • display: flex; - Define um contêiner como flexível.
  • flex-direction: - Controla a direção dos itens flexíveis (row, column, row-reverse, column-reverse).
  • justify-content: - Alinha os itens flexíveis ao longo do eixo principal (flex-start, flex-end, center, space-between, space-around).
  • align-items: - Alinha os itens flexíveis ao longo do eixo transversal (flex-start, flex-end, center, baseline, stretch).
  • flex-wrap: - Controla se os itens flexíveis devem quebrar para a próxima linha (nowrap, wrap, wrap-reverse).

1.2- Eixos

O Flexbox trabalha com dois eixos principais: o eixo principal e o eixo transversal. O eixo principal é a direção em que os itens flexíveis são organizados, enquanto o eixo transversal é perpendicular ao eixo principal. A direção do eixo principal é controlada pela propriedade flex-direction, e a direção do eixo transversal é controlada pela propriedade align-items.

1.3- Anatomia dos itens do flexbox

Os itens do Flexbox possuem algumas propriedades específicas que controlam seu comportamento dentro do contêiner flexível. Algumas dessas propriedades incluem:

  • order: - Controla a ordem dos itens flexíveis dentro do contêiner.
  • flex-grow: - Controla a capacidade de um item flexível crescer para preencher o espaço disponível.
  • flex-shrink: - Controla a capacidade de um item flexível encolher para se ajustar ao espaço disponível.
  • flex-basis: - Define a base do item flexível antes de crescer ou encolher.

Para ativar todas as propriedades do Flexbox, basta adicionar a propriedade display: flex; ao contêiner.

2- Grid Layout

O Grid Layout é um modelo de layout em CSS que permite criar layouts bidimensionais, organizando os elementos em linhas e colunas. Ele é especialmente útil para criar layouts complexos e responsivos, oferecendo uma maneira fácil de controlar o posicionamento dos elementos em uma grade. O Grid Layout é amplamente utilizado para criar interfaces de usuário modernas e responsivas, permitindo que os desenvolvedores criem layouts flexíveis e adaptáveis a diferentes tamanhos de tela.

2.1- Propriedades do Grid Layout

O Grid Layout possui várias propriedades que controlam o comportamento dos elementos dentro da grade. Algumas das principais propriedades incluem:

  • display: grid: - Define um contêiner como uma grade.
  • grid-template-columns: - Define o número e o tamanho das colunas na grade.
  • grid-template-rows: - Define o número e o tamanho das linhas na grade.
  • grid-gap: - Define o espaço entre as linhas e colunas na grade.
  • grid-template-areas: - Define áreas nomeadas na grade para facilitar o posicionamento dos elementos.
  • justify-items: - Alinha os itens dentro das células da grade ao longo do eixo horizontal (start, end, center, stretch).
  • align-items: - Alinha os itens dentro das células da grade ao longo do eixo vertical (start, end, center, stretch).
  • grid-auto-flow: - Controla o fluxo automático dos itens na grade (row, column, dense).
  • grid-auto-columns: - Define o tamanho das colunas automáticas na grade.
  • grid-auto-rows: - Define o tamanho das linhas automáticas na grade.
  • place-items: - Controla o posicionamento dos itens dentro das células da grade ao longo de ambos os eixos.
  • place-content: - Controla o posicionamento do conteúdo dentro da grade ao longo de ambos os eixos.
  • grid-template: - Uma shorthand para definir grid-template-columns, grid-template-rows e grid-template-areas.
  • Função repeat(): - Permite repetir valores em propriedades do Grid Layout.
  • Unidade fraction: - Permite repetir valores em propriedades do Grid Layout.

2.2- Anatomia do Grid Layout

O Grid Layout possui uma estrutura de linhas e colunas que formam células onde os elementos podem ser posicionados. Os elementos dentro da grade podem ser posicionados usando as propriedades grid-row e grid-column, que permitem especificar a linha e a coluna onde o elemento deve ser colocado. Além disso, o Grid Layout oferece a capacidade de criar áreas nomeadas usando a propriedade grid-template-areas, facilitando o posicionamento dos elementos na grade.

Shorthands de itens para Grid Layout

O Grid Layout possui algumas propriedades shorthand que permitem definir várias propriedades de uma só vez. Algumas dessas propriedades incluem:

  • grid-start: - Define a linha de início para um item na grade.
  • grid-end: - Define a linha de término para um item na grade.
  • grid-area: - Define a área de um item na grade, combinando as propriedades grid-row-start, grid-column-start, grid-row-end e grid-column-end.
  • grid-row: - Permite definir a linha de início e término para um item na grade em uma única declaração.
  • grid-column: - Permite definir a coluna de início e término para um item na grade em uma única declaração.
