1- Cores com CSS

Para representar cores em CSS, podemos usar diferentes métodos:

  • Nomes de cores: Podemos usar nomes de cores predefinidos, como "red", "blue", "green", etc.
  • Valores hexadecimais: Representam as cores usando um código hexadecimal, como "#FF0000" para vermelho, "#00FF00" para verde, e "#0000FF" para azul.
  • Valores RGB: Especificam as cores usando os valores de vermelho, verde e azul, como "rgb(255, 0, 0)" para vermelho, "rgb(0, 255, 0)" para verde, e "rgb(0, 0, 255)" para azul.
  • Valores RGBA: Semelhante ao RGB, mas inclui um valor de opacidade (alfa), como "rgba(255, 0, 0, 0.5)" para vermelho semi-transparente.

2.1- Propriedades de cor em CSS

Existem várias propriedades em CSS que permitem controlar as cores dos elementos:

  • color: Define a cor do texto.
  • background-color: Define a cor de fundo de um elemento.
  • border-color: Define a cor da borda de um elemento.
  • outline-color: Define a cor do contorno de um elemento.

3- Paleta de cor

Uma paleta de cores é uma seleção de cores que são usadas em um projeto de design. Ela ajuda a criar uma identidade visual consistente e a transmitir a mensagem desejada. Existem várias ferramentas online que permitem criar paletas de cores, como Adobe Color, Coolors e Paletton.

Com isso, podemos criar designs mais harmoniosos e profissionais.

4- Centralização de texto

Para centralizar o texto em CSS, podemos usar a propriedade "text-align" com o valor "center". junto com a propriedade "margin" para centralizar horizontalmente. Exemplo:

        .centralizado {
            text-align: center;
            margin: 0 auto;
        }

Isso fará com que o texto dentro do elemento com a classe "centralizado" seja centralizado horizontalmente na página.

5- Anatomia da tipografia

A tipografia é a arte e técnica de arranjar tipos para tornar a linguagem escrita legível, atraente e eficaz. A anatomia da tipografia inclui vários termos importantes:

  • Ascendente: A parte de uma letra que se estende acima da linha de base, como a parte superior de "b", "d", "h", etc.
  • Descendente: A parte de uma letra que se estende abaixo da linha de base, como a parte inferior de "g", "j", "p", etc.
  • Linha de base: A linha imaginária sobre a qual as letras se assentam.
  • Altura da linha: A distância entre a linha de base e a parte superior de uma letra.
  • Serifa: As pequenas linhas ou traços que se estendem das extremidades das letras em algumas fontes, como "Times New Roman".
  • Sans-serif: Fontes sem serifa, como "Arial" e "Helvetica".

Você pode usar o google fonts para selecionar e integrar fontes gratuitas em seu projeto. usando a <@import (linkdosite) >.

6- Tamanho e medidas

Em CSS, podemos usar diferentes unidades de medida para definir o tamanho dos elementos. As unidades mais comuns incluem:

  • Pixels (px): Uma unidade fixa que representa um ponto na tela. Por exemplo, "font-size: 16px;" define o tamanho da fonte como 16 pixels.
  • Em (em): Uma unidade relativa que é baseada no tamanho da fonte do elemento pai. Por exemplo, "font-size: 2em;" define o tamanho da fonte como o dobro do tamanho da fonte do elemento pai.
  • Rem (rem): Semelhante ao em, mas é baseado no tamanho da fonte do elemento raiz (geralmente o elemento ). Por exemplo, "font-size: 1.5rem;" define o tamanho da fonte como 1.5 vezes o tamanho da fonte do elemento raiz.
  • Porcentagem (%): Uma unidade relativa que é baseada no tamanho do elemento pai. Por exemplo, "font-size: 150%;" define o tamanho da fonte como 150% do tamanho da fonte do elemento pai.

Usar unidades relativas como em, rem e porcentagem pode ajudar a criar designs mais responsivos e adaptáveis a diferentes tamanhos de tela.

Com isso, para utilizar essas unidades de medida de forma eficaz, é importante entender como elas se comportam em relação ao elemento pai e ao elemento raiz. Exemplo:

    .elemento {
        font-size: 1.5em; /* O tamanho da fonte será 1.5 vezes o tamanho da fonte do elemento pai */
    }

Isso permitirá que o design seja mais flexível e se adapte melhor a diferentes dispositivos e tamanhos de tela.
