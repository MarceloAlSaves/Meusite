1- Introdução ao Iframe e formulários

O elemento <iframe> é usado para incorporar outro documento HTML dentro do documento atual. Ele permite que você exiba conteúdo de outra página web, como um vídeo do YouTube, um mapa do Google ou até mesmo outro site completo, dentro da sua própria página, você pode usar qualquer incorporação de algum site que você desejar.

1.1- Navegação em Iframes

Para navegar dentro de um iframe, você pode usar o atributo "src" para especificar a URL do conteúdo que deseja exibir. Por exemplo:

<iframe src="https://www.example.com" width="600" height="400"></iframe>

Isso criará um iframe que exibe o conteúdo do site "example.com" com uma largura de 600 pixels e uma altura de 400 pixels.

A tag name é usada para dar um nome ao iframe, permitindo que ele seja referenciado por outros elementos da página.

A tag srdoc é usada para especificar o documento que será exibido dentro do iframe.

1.2- Segurança em Iframes

Ao usar iframes, é importante considerar questões de segurança. O conteúdo exibido dentro de um iframe pode ser controlado por terceiros, o que pode representar riscos de segurança, como ataques de clickjacking ou injeção de conteúdo malicioso. Para mitigar esses riscos, é recomendável usar o atributo "sandbox" para restringir as ações que o conteúdo do iframe pode realizar. Por exemplo:

<iframe src="https://www.example.com" width="600" height="400" sandbox></iframe>

O atributo "sandbox" pode ser configurado com diferentes valores para permitir ou restringir ações específicas, como permitir scripts, formulários ou pop-ups.

3- Formulários

Os formulários são usados para coletar informações dos usuários. Eles podem incluir campos de texto, caixas de seleção, botões de rádio e outros elementos de entrada. Para criar um formulário, você pode usar a tag <form> e incluir os elementos de entrada dentro dela. Você também pode colocar atribuitos ao formulário como Required(que precisa colocar algo) Por exemplo o metodo get:

            <form>
                <autocomplete<=off>
                <label for="nome">Nome:
                <input type="text" id="nome" name="nome"><br><br>
                <label for="email">Email:
                <input type="email" id="email" name="email"><br><br>
                <input type="submit" value="Enviar">
            <form>

O método "get" é usado para enviar os dados do formulário como parte da URL, enquanto o método "post" envia os dados no corpo da requisição, proporcionando maior segurança para informações sensíveis. So que aparece os dados no Dev Tools.

Alterando o type, você pode criar diferentes tipos de botões para enviar o formulário. Como name, password, email, etc.

Input Especial de numero, você pode usar o comando Step, Fazendo que o usuário só possa inserir valores numéricos dentro de um intervalo específico. 1,5 ,2 ,2,5 etc.

4- Media queries

As media queries são usadas para aplicar estilos CSS diferentes com base nas características do dispositivo ou da tela. Elas permitem que você crie designs responsivos que se adaptam a diferentes tamanhos de tela, como desktops, tablets e smartphones.

Exemplo de media query para telas com largura máxima de 600 pixels:

@media (max-width: 600px) {
        body {
            background-color: lightblue;
        }

Isso fará com que o plano de fundo do corpo da página fique azul claro em dispositivos com largura de tela de 600 pixels ou menos. Você pode usar diferentes condições nas media queries, como min-width, max-width, orientation e outras para criar estilos específicos para diferentes dispositivos e orientações de tela.

4.5- media features

As media features são características específicas que podem ser usadas em media queries para aplicar estilos CSS com base em diferentes condições. Algumas das media features mais comuns incluem:

  • width: A largura da viewport do dispositivo.
  • height: A altura da viewport do dispositivo.
  • orientation: A orientação do dispositivo (portrait ou landscape).resolution: A resolução da tela do dispositivo.
  • aspect-ratio: A proporção entre a largura e a altura da viewport.

Essas media features permitem que você crie designs responsivos e adaptáveis, garantindo que seu site seja exibido corretamente em uma variedade de dispositivos e tamanhos de tela.

5- Mobile First

O conceito de "Mobile First" é uma abordagem de design e desenvolvimento web que prioriza a criação de experiências otimizadas para dispositivos móveis antes de se preocupar com versões para desktop. Isso significa que os designers e desenvolvedores começam a projetar e construir o site pensando primeiro na experiência do usuário em smartphones e tablets, garantindo que o conteúdo seja acessível, legível e fácil de navegar em telas menores.

5.5- Device Breakpoints

Os device breakpoints são pontos de interrupção específicos usados em media queries para definir estilos CSS diferentes com base no tamanho da tela do dispositivo. Eles ajudam a criar designs responsivos que se adaptam a diferentes dispositivos, como smartphones, tablets e desktops. Alguns breakpoints comuns incluem:

  • 320px: Dispositivos móveis pequenos (smartphones)
  • 768px: Dispositivos móveis grandes e tablets
  • 1024px: Desktops e laptops
